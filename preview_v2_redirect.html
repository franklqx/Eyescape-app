Eyescape v2 · Redirect Preview

From digital pet → screen-time + 20-20-20 + eye exercises

Pet UI removed (code preserved for v3+). HomeView restructured into a three-segment data view. New: PickupSession tracking, ScreenTimeAggregator, eye-exercise library (AAO + 教育部 2008), Family Controls scaffold.

What changed

Removed (parked for v3+)

  • Pet visualization (cat-pixel, mood states)
  • Pet bubble dialogue + tap-to-talk
  • Pet name editing in Settings
  • Cat icon in Dynamic Island compact / minimal / expanded
  • Pet early-bird / bedtime notifications
  • Pet 7-day grace-period mood floor

Now (v2.0)

  • Today stats grid: total · avg pickup · ≤20-min compliance · exercises
  • Eye exercises: 2-min Quick rest · 3-min Palming · 5-min Classic (CN MoE)
  • Auto-protect on launch: no Start button — just opens watching
  • SessionStatusBar: state-aware dot + Pause / Resume / Start
  • Connect Screen Time CTA in Settings (Family Controls auth)
  • Amber eye.fill glyph replaces cat in Dynamic Island
Three core screens
All numbers are illustrative samples. Layouts match the actual SwiftUI implementation in HomeView.swift, EyeExerciseSession.swift, AnalyticsView.swift, SettingsView.swift.
