Design notes

Design decisions

  • Hero 指标:最长一次会话,不是日总时长 · 这才对应"对眼睛的连续压力"。Apple Screen Time 强调总时长 = 制造耻辱;我们强调最长会话 = 提示分散使用。
  • 3 级层次 · L1 总览(类别排序) → L2 类别(app 列表) → L3 单 app(hourly + 会话日志)。每级都有自己的 hero、sub-stats、范围切换。
  • 合规日 vs 不合规日 · 同一 Home 布局,语气不同。合规走 sage 庆祝 + maintenance 推荐;不合规走 amber 警示 + 上下文化"为什么"。
  • 没有 streak · 按你说的去掉。compliant day 的庆祝靠 hero sage 色 + 文案("All sessions stayed under 20 min")。
  • API 局限的提醒 · 单 app "最长一次会话" 需要 DeviceActivityMonitor extension 自埋点(基础 DeviceActivity 只给总时长 + hourly 分布)。这意味着 v2 ship 前需要做 monitor extension,不只是 report extension。
  • 类别色板 · 与暖调整体协调:Social 琥珀 / Entertainment 桃 / Productivity 苔 / Games 暗紫 / Creativity 蓝灰。颜色用于 stacked bar + cat dot 标记。
